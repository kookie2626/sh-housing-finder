# SH 단지찾기

SH 사이트에서 **장기전세 단지의 공가수와 예비자수를 확인하러 가는 과정**을 돕는 개인 프로젝트입니다. 
단지명을 검색해 공식 상세페이지로 이동할 수 있게 만들었습니다.

**[서비스 사용하기](https://kookie2626.github.io/sh-housing-finder/)** · [CSV 내려받기](data/apartments.csv)

## 만들게 된 이유

SH 사이트에서 관심 단지의 **공가수와 예비자수**를 확인하려 했습니다. 그런데 단지명이 최신 이름으로 갱신되지 않은 곳은 이름을 검색해도 나오지 않아 원하는 정보를 확인하러 가기 어려웠습니다.

단지명이 검색되지 않거나 상세화면의 이름이 비어 있어도, 해당 단지의 코드와 주소·공급정보는 등록되어 있는 경우가 있었습니다. 이 프로젝트는 코드별 단지정보를 확인하고 실제 이름과 주소를 연결해, 사용자가 SH 공식 상세페이지에 접근할 수 있도록 만든 목록입니다.

SH에는 여러 임대 유형이 있지만 **우선적으로 장기전세를 살펴보는 것**이 출발점입니다. 다른 공급유형도 목록에 포함하며 검색과 공급유형 필터로 구분합니다.

### 현재 제공하는 것과 확인할 곳

- 이 사이트: 단지 검색, 주소·공급유형 확인, SH 상세페이지 연결
- SH 공식 사이트: 현재 공가수·예비자수와 관련 공급정보 확인

**현재 이 프로젝트는 공가수·예비자수를 직접 수집하거나 실시간으로 표시하지 않습니다.** 해당 수치는 SH 공식 페이지에서 확인해야 합니다. 목록의 ‘SH 임대세대수’는 공가수나 예비자수가 아닙니다.

## 주요 기능

- 단지명·주소·코드·공급유형 검색 — 띄어쓰기 차이를 무시하고 여러 검색어를 함께 입력할 수 있습니다.
- 장기전세 등 공급유형·자치구 필터와 이름 누락·확인 필요 항목 구분
- 현재 적용된 목록 필터 표시와 한 번에 조건 초기화
- 표 형태의 목록, 코드순·이름순 정렬
- SH 공식 상세페이지 및 이름 대조 출처 링크
- 현재 검색 결과의 CSV 다운로드
- 브라우저에 저장하는 관심 목록

검색과 필터는 브라우저에서 처리합니다. 별도의 로그인·데이터베이스·서버 API가 필요하지 않습니다. 관심 목록은 다른 방문자와 공유되지 않습니다.

## 데이터 범위와 한계

| 항목 | 내용 |
| --- | --- |
| 확인일 | 2026-10-28 |
| 대상 | SH 주택정보의 `ctgrCd=10` (‘아파트 등’) |
| 확인한 코드 구간 | `70111` ~ `70700` 연속 확인 + `0` ~ `80000` 중 258개 표본 확인 |
| 수록 | 이름 또는 유의미한 주소를 확인한 **500개 코드** |
| 원문 | [SH 주택정보](https://www.i-sh.co.kr/houseinfo/main/mainPage.do) |

**서울 전체 임대주택 목록이 아닙니다.** LH 등 다른 공급기관과 확인하지 않은 SH 항목은 포함하지 않습니다. 0~80000의 모든 코드를 확인한 것은 아닙니다. 같은 단지가 공급유형 등에 따라 여러 코드로 나뉠 수 있으므로 500개가 서로 다른 단지 500곳을 뜻하지 않습니다. ‘아파트 등’에는 오피스텔·다세대주택도 포함됩니다.

- 단지명은 SH 상세화면 표기를 우선 사용합니다.
- 이름이 비어 있는 항목은 주소와 외부 자료를 대조했으며 출처를 각 항목에 남겼습니다.
- 주소 충돌이 있는 항목은 단지명을 확정하지 않고 ‘확인 필요’로 표시합니다.
- 세대수는 전체 단지 규모가 아닌 **SH 임대 세대수**입니다.
- 공급정보가 0 또는 미등록인 항목은 현재 모집·공급 가능 여부를 의미하지 않습니다.
- 데이터는 자동 갱신되지 않습니다. 실제 신청·모집 정보는 SH 원문과 공고문에서 확인해야 합니다.

공식 SH 서비스가 아닌 개인 프로젝트입니다. 원출처의 이미지나 전체 페이지를 복제하지 않고 단지 정보와 출처 링크를 제공합니다.

## 실행 방법

저장소를 내려받아 `index.html`을 브라우저에서 열면 됩니다. 로컬 서버를 사용하려면 프로젝트 폴더에서 다음을 실행하세요.

```sh
python3 -m http.server 8000
```

이후 `http://localhost:8000`에 접속합니다. 외부 SH·출처 링크를 열 때는 인터넷 연결이 필요합니다.

## 프로젝트 구조

```text
index.html             페이지 구조
assets/styles.css      반응형 스타일
assets/app.js          검색·필터·관심 목록·CSV 내보내기
assets/data.js         브라우저용 데이터
data/apartments.json  관리용 데이터 원본
data/apartments.csv   공유용 데이터
scripts/sync_data.py   JSON을 브라우저 데이터와 CSV에 반영
```

## 데이터 수정

`data/apartments.json`을 수정한 뒤 다음을 실행합니다.

```sh
python3 scripts/sync_data.py
```

새 항목을 추가할 때는 SH 원문에서 코드·단지명·주소·공급정보를 확인하고, 외부 자료로 이름을 대조했다면 `source`에 출처를 넣어주세요. 확인이 어려운 값은 추정해 채우기보다 `status`와 `note`에 표시합니다.

| 필드 | 의미 |
| --- | --- |
| `code` | SH `biznsCd` |
| `name`, `shName` | 표시할 이름 / SH 원문 이름 |
| `address`, `district` | SH 주소 / 자치구 |
| `type`, `units`, `sizes` | 공급유형 / 임대세대수 / 공급형 |
| `hidden` | 확인 당시 SH 상세화면 이름 누락 여부 |
| `status`, `note` | 확인 상태와 주의할 내용 |
| `url`, `source` | SH 상세페이지 / 이름 대조 출처 |

## 설계 선택

- 프레임워크 없이 HTML·CSS·JavaScript로 구성해 설치와 배포를 단순하게 했습니다.
- 공개 사이트가 SH에 실시간 요청을 보내는 대신 확인한 데이터의 스냅샷을 사용합니다.
- 이름 누락 항목을 버리지 않고 주소로 보완하되, 출처와 불확실성을 함께 보여줍니다.
- GitHub Pages의 정적 호스팅으로 운영할 수 있습니다.

## 오류 제보

틀린 단지명·주소·링크를 발견하면 [Issues](https://github.com/kookie2626/sh-housing-finder/issues)에 코드와 확인한 출처를 남겨주세요. 개인정보나 신청자 정보는 올리지 마세요.

## 검색 결과가 보이지 않을 때

‘이름 누락’은 등록된 이름이 비어 있던 항목만 보여주는 필터입니다. 이름이 정상 등록된 단지는 이 필터에서 보이지 않습니다. ‘전체’으로 전환하거나 ‘조건 초기화’를 누른 뒤 검색하세요.

예를 들어 **잠실래미안아이파크 (`70616`)**는 수록되어 있지만 ‘이름 누락’ 대상은 아닙니다. `잠실래미안아이파크`, `70616`, `올림픽로 393`으로 검색할 수 있습니다.
